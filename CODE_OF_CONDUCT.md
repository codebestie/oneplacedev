# Code of Conduct

## Our Pledge

We pledge to make the One Place Dev community welcoming, safe, inclusive, and equitable for all contributors.

One Place Dev is an open-source platform focused on helping developers discover, access, and contribute to useful development resources from a centralized location. We are committed to fostering an environment that respects and promotes the dignity, rights, and contributions of all individuals regardless of experience level, background, identity, nationality, language, religion, gender, sexual orientation, disability, or other personal characteristics.

Participation in this project is open to everyone who contributes in good faith and follows this Code of Conduct.

## Encouraged Behaviors

As members of the One Place Dev community, we strive to:

1. Respect the purpose of the project and its contributors.
2. Be welcoming to new contributors and learners.
3. Communicate kindly, honestly, and professionally.
4. Respect different viewpoints and technical approaches.
5. Give and receive constructive feedback gracefully.
6. Take responsibility for our actions and contributions.
7. Help improve the project through collaboration and knowledge sharing.
8. Support an inclusive and positive open-source environment.

## Restricted Behaviors

The following behaviors are not allowed:

1. Harassment, bullying, intimidation, or discrimination.
2. Personal attacks, insults, or derogatory comments.
3. Trolling or intentionally disruptive behavior.
4. Sharing private information without consent.
5. Hate speech or discriminatory language.
6. Plagiarism or submitting copied work without proper attribution.
7. Spam, self-promotion, or commercial advertising unrelated to the project.
8. Any behavior that negatively impacts the safety and well-being of community members.

## Reporting an Issue

If you experience or witness behavior that violates this Code of Conduct, please report it through:

* GitHub Issues (for public project concerns)
* GitHub Discussions
* Direct contact with project maintainers

All reports will be reviewed respectfully and confidentially whenever possible.

Project maintainers will make reasonable efforts to investigate reports, communicate outcomes when appropriate, and take corrective action when necessary.

## Addressing and Repairing Harm

Maintainers may take one or more of the following actions depending on severity:

1. Warning
2. Temporary restriction of participation
3. Temporary suspension
4. Permanent ban from project spaces

Enforcement decisions will be made with the goal of maintaining a safe, productive, and welcoming community.

## Scope

This Code of Conduct applies to all One Place Dev community spaces, including:

* GitHub repositories
* Issues
* Pull Requests
* Discussions
* Project documentation
* Community events and communication channels

It also applies when representing the project publicly.
